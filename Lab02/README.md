N = 14, K = 1, a = 2, b = 2, c = 4

Масив: 24 випадкових числа в діапазоні [1; 4].

Матриця: 3 × 6, числа в діапазоні [1; 4].

Генератор випадкових чисел: new Random(14).

# Завдання

- **Task1** — агрегація: сума, середнє, мінімум і максимум з індексами, кількість нулів.
- **Task2** — фільтрація елементів, менших за `K % 5 = 1`.
- **Task3** — пошук найдовшої серії однакових елементів.
- **Task4** — обмін першої та другої половини масиву без створення другого масиву.
- **Task5** — створення матриці, суми рядків, максимуми стовпців та рядок із найбільшою сумою.
